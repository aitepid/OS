1. 专利说明书 (Specification) -- 最高优先级
======================================================================

源文件:
  - USPTO_PATENT_01_HILBERT_CURVE_OS.txt        (专利 #1)
  - USPTO_PATENT_02_SELF_BOOTSTRAP_TOOLCHAIN.txt (专利 #2)

目标格式: DOCX (Microsoft Word), 每份专利拆分为 3 个 DOCX 文件

  输出文件 (专利 #1):
    [ ] Patent01_Specification.docx  -- 说明书正文
    [ ] Patent01_Claims.docx         -- 权利要求书
    [ ] Patent01_Abstract.docx       -- 摘要

  输出文件 (专利 #2):
    [ ] Patent02_Specification.docx  -- 说明书正文
    [ ] Patent02_Claims.docx         -- 权利要求书
    [ ] Patent02_Abstract.docx       -- 摘要

格式要求 (37 C.F.R. 1.52):
  [ ] 字体: Times New Roman 12pt 或等宽字体
  [ ] 行距: 双倍行距 (Double spacing)
  [ ] 行号: 左侧连续行号 (Word -> 布局 -> 行号 -> 连续)
  [ ] 页边距: 上/左 2.5cm, 右 1.5cm, 下 1.0cm
  [ ] 页码: 底部居中
  [ ] 纸张: Letter (8.5" x 11") 或 A4

操作步骤:
  1. 打开 Word, 新建文档, 设置上述格式
  2. 从 TXT 文件复制正文部分 (标题 ~ 详细描述)
  3. 将 CLAIMS 部分单独复制到 Claims.docx
  4. 将 ABSTRACT 部分单独复制到 Abstract.docx
  5. 删除 TXT 中的 "INVENTOR(S)" / "ASSIGNEE" / "FILING CHECKLIST" 段落
     (这些信息通过 ADS 和 Declaration 表单单独提交)
  6. 保存为 DOCX, 然后导出 PDF 备用

Patent Center 上传:
  Document type: "Specification"     -> Patent0X_Specification.docx
  Document type: "Claims"            -> Patent0X_Claims.docx
  Document type: "Abstract"          -> Patent0X_Abstract.docx

格式要求 (37 C.F.R. 1.84):

  [ ] 纸张: 8.5" x 11" 或 A4
  [ ] 页边距: 上 2.5cm, 左 2.5cm, 右 1.5cm, 下 1.0cm
  [ ] 参考标号: 至少 0.32cm (1/8 inch) 高
  [ ] 线条: 清晰、锐利、实线
  [ ] 阴影: 仅使用斜平行线
  [ ] 每页一幅图, 图号标注在顶部 (如 "FIG. 1")

推荐绘图工具:
  - Draw.io (diagrams.net) -- 免费, 可导出 PDF
  - Microsoft Visio -- 专业绘图
  - PowerPoint -- 简单图形
  - Inkscape -- 开源矢量图编辑器

操作步骤:
  1. 打开 USPTO_DRAWING_SPECS.txt, 逐图阅读描述
  2. 用绘图工具按描述绘制每幅图
  3. 添加参考标号 (100, 110, 120... 等)
  4. 导出为 PDF, 每页一幅图
  5. 合并为单一 PDF 文件 (每份专利一个)

Patent Center 上传:
  Document type: "Drawings-only black and white line drawings"
