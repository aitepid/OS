FIG. 3 -- Bit-Interleaving Encoding Flowchart (interleave3)
================================================================

    +-------+
    | START |
    +---+---+
        |
        v
  +-------------+
  | r = 0       |
  | i = 0       |
  +------+------+
         |
         v
    +----+-----+        +---------------------------+
    | i < 10 ? |--Yes-->| bit_x = x mod 2           |
    +----+-----+        | bit_y = y mod 2           |
         |              | bit_z = z mod 2           |
         No             +-------------+-------------+
         |                            |
         v                            v
    +---------+         +---------------------------+
    | Return  |         | shift_x = 2^(3*i)        |
    | r       |         | shift_y = 2^(3*i + 1)    |
    | (30-bit |         | shift_z = 2^(3*i + 2)    |
    |  key)   |         +-------------+-------------+
    +----+----+                       |
         |                            v
         v              +---------------------------+
      +-----+          | r = r + bit_x * shift_x   |
      | END |          |   + bit_y * shift_y        |
      +-----+          |   + bit_z * shift_z        |
                        +-------------+-------------+
                                      |
                                      v
                        +---------------------------+
                        | x = x / 2                 |
                        | y = y / 2                 |
                        | z = z / 2                 |
                        | i = i + 1                 |
                        +-------------+-------------+
                                      |
                                      +----> (loop back to "i < 10 ?")


FIG. 4 -- Reverse Decoding Flowchart (deinterleave3)
================================================================

    +-------+
    | START |
    +---+---+
        |
        v
  +--------------+
  | x=0, y=0    |
  | z=0, i=0    |
  | kk = k      |
  +------+-------+
         |
         v
    +----+-----+        +---------------------------+
    | i < 10 ? |--Yes-->| pow = 2^i                 |
    +----+-----+        +-------------+-------------+
         |                            |
         No                           v
         |              +---------------------------+
         v              | x += (kk mod 2) * pow     |
    +-----------+       | kk = kk / 2               |
    | Return    |       +-------------+-------------+
    | [x, y, z] |                     |
    +-----------+                     v
                        +---------------------------+
                        | y += (kk mod 2) * pow     |
                        | kk = kk / 2               |
                        +-------------+-------------+
                                      |
                                      v
                        +---------------------------+
                        | z += (kk mod 2) * pow     |
                        | kk = kk / 2               |
                        | i = i + 1                 |
                        +-------------+-------------+
                                      |
                                      +----> (loop back to "i < 10 ?")

FIG. 6 -- IPC Spatial Routing Mechanism
================================================================

  +-------------------+                        +-------------------+
  | Sender Subsystem  |                        | Receiver Subsystem|
  | Hilbert key: Ka   |                        | Hilbert key: Kb   |
  +--------+----------+                        +--------+----------+
           |                                            ^
           v                                            |
      +----+--------------------------------------------+----+
      |          Hilbert Distance Calculator                 |
      |          dist = |Ka - Kb|                            |
      +----+---------------------+--------------------------+
           |                     |
           v                     v
    +--------------+      +--------------+
    | dist < THR ? |      | dist >= THR  |
    +--------------+      +--------------+
           |                     |
           v                     v
    +--------------+      +--------------+
    | Fast Path    |      | Standard     |
    | (shared mem) |      | Pipe         |
    +--------------+      +--------------+

    +-----------------------------------------------+
    | 0x700000  IPC Pipes (32 channels)             |
    | [pipe0][pipe1][pipe2]...[pipe31]              |
    +-----------------------------------------------+
    | 0x730000  Message Queues (16 queues)          |
    | [mq0][mq1][mq2]...[mq15]                     |
    +-----------------------------------------------+

FIG. 8 -- Hilbert-Aware Memory Allocator
================================================================

    +---------------------------------------------+
    | Allocation Request                          |
    | (from subsystem at Hilbert key K)           |
    +----------------------+----------------------+
                           |
                           v
    +---------------------------------------------+
    | Sorted Free Page List                       |
    | (sorted by Hilbert key, merge-sort)         |
    |                                             |
    | [key=102, pf=0x200] [key=107, pf=0x340]    |
    | [key=115, pf=0x500] [key=128, pf=0x680]    |
    | [key=142, pf=0x720] [key=156, pf=0x900]    |
    +----------------------+----------------------+
                           |
          "Select nearest key to K"
                           |
                           v
    +---------------------------------------------+
    | Allocated Page                              |
    | (key closest to K -> best locality)         |
    +---------------------------------------------+

    +---------------------------+
    | Merge Sort                |
    | O(n log n)                |
    | Iterative bottom-up       |
    +---------------------------+
