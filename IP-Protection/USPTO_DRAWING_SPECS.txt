  - Top margin: 2.5 cm; Left margin: 2.5 cm

  - Reference numerals must be at least 0.32 cm (1/8 inch) high
  - All lines must be clean, sharp, and solid

FIG. 3 -- Bit-Interleaving Encoding Flowchart (interleave3)
----------------------------------------------------------------------
Type: Flowchart
Steps:
  Start -> Initialize r=0, i=0
  -> Loop condition: i < 10?
  -> Yes: Extract bit_x = x mod 2, bit_y = y mod 2, bit_z = z mod 2
  -> Compute shifts: shift_x = 2^(3i), shift_y = 2^(3i+1),
     shift_z = 2^(3i+2)
  -> Accumulate: r = r + bit_x*shift_x + bit_y*shift_y + bit_z*shift_z
  -> Right-shift: x=x/2, y=y/2, z=z/2
  -> i = i + 1 -> Loop back
  -> No: Return r (30-bit Hilbert key)
  -> End


FIG. 4 -- Reverse Decoding Flowchart (deinterleave3)
----------------------------------------------------------------------
Type: Flowchart
Steps:
  Start -> Initialize x=0, y=0, z=0, i=0, kk=k
  -> Loop condition: i < 10?
  -> Yes: pow = 2^i
  -> x += (kk mod 2) * pow; kk = kk/2
  -> y += (kk mod 2) * pow; kk = kk/2
  -> z += (kk mod 2) * pow; kk = kk/2
  -> i = i + 1 -> Loop back
  -> No: Return [x, y, z]
  -> End

FIG. 9 -- CPU Mode Transition Sequence
----------------------------------------------------------------------
Type: State diagram / flowchart
Elements:
  State: "16-bit Real Mode" (entry)
  -> CLI, LGDT
  -> Set CR0.PE = 1
  -> Far JMP selector 8
  State: "32-bit Protected Mode"
  -> Copy kernel to 0x100000 (REP MOVSD)
  -> Build page tables (PML4/PDPT/PD at 0x1000)
  -> Set CR3 = PML4
  -> Set CR4.PAE = 1
  -> Set EFER.LME = 1 (MSR 0xC0000080)
  -> Set CR0.PG = 1
  -> Far JMP selector 24
  State: "64-bit Long Mode" (target)
  -> Set RSP = 0x70000
  -> JMP kernel_entry
