USPTO FILING CHECKLIST AND PROCEDURE GUIDE
======================================================================

Step-by-step guide for filing both HicOS patent applications
via Patent Center (https://patentcenter.uspto.gov).


======================================================================
PRE-FILING PREPARATION
======================================================================

  Phase 1: Attorney Engagement (Weeks 1-2)

    [ ] Identify and contact a registered USPTO patent attorney
        or agent
        - Search at: https://oedci.uspto.gov/OEDCI/
        - Look for experience in CPC classes:
          G06F 9/44 (OS), G06F 8/41 (Compilers),
          G06F 12/02 (Addressing)
    [ ] Provide attorney with this entire IP-Protection folder
    [ ] Discuss filing strategy:
        - Non-provisional vs. provisional first
        - US only vs. PCT international
        - Single vs. multiple applications

  Phase 2: Prior Art Search (Weeks 2-4)

    [ ] Attorney conducts professional prior art search
    [ ] Review search results
    [ ] Refine claims based on search findings
    [ ] Prepare Information Disclosure Statement (IDS)
        See: USPTO_IDS.txt

  Phase 3: Document Preparation (Weeks 4-8)

    [ ] Attorney reviews and revises specification text
        - USPTO_PATENT_01_HILBERT_CURVE_OS.txt
        - USPTO_PATENT_02_SELF_BOOTSTRAP_TOOLCHAIN.txt
    [ ] Commission formal patent drawings
        See: USPTO_DRAWING_SPECS.txt
        - Application #1: 10 figures
        - Application #2: 12 figures
    [ ] Prepare Application Data Sheet (ADS)
        See: USPTO_APPLICATION_DATA_SHEET.txt
    [ ] Prepare inventor declaration
        See: USPTO_DECLARATION.txt
    [ ] Determine entity status
        See: USPTO_MICRO_ENTITY_CERT.txt


======================================================================
FILING PROCEDURE -- APPLICATION #1
(Hilbert Curve OS Architecture)
======================================================================

  Step 1: Create Patent Center Account
    [ ] Go to https://patentcenter.uspto.gov
    [ ] Create account or log in with existing USPTO account
    [ ] Set up payment method

  Step 2: Start New Application
    [ ] Select "Utility Non-Provisional" application type
    [ ] Enter application data from ADS

  Step 3: Upload Documents (in order)
    [ ] Specification (USPTO_PATENT_01_HILBERT_CURVE_OS.txt,
        converted to PDF by attorney)
        Document type: "Specification"
    [ ] Claims (included in specification, or separate document)
        Document type: "Claims"
    [ ] Abstract (included in specification, or separate document)
        Document type: "Abstract"
    [ ] Drawings (10 figures, formal patent drawings)
        Document type: "Drawings-only black and white line drawings"
    [ ] Inventor Declaration (signed PTO/AIA/01)
        Document type: "Oath or Declaration filed"
    [ ] Application Data Sheet (completed PTO/AIA/14)
        Document type: "Application Data Sheet"
    [ ] Information Disclosure Statement (IDS)
        Document type: "Information Disclosure Statement (IDS)"
        Plus: copies of all NPL references (PDFs)
    [ ] Micro Entity Certification (if applicable)
        Document type: "Petition to Make Special"
        OR use PTO/SB/15A form

  Step 4: Pay Fees
    [ ] Basic filing fee: $80 (micro entity)
    [ ] Search fee: $160 (micro entity)
    [ ] Examination fee: $192 (micro entity)
    [ ] Total: $432
    [ ] Verify entity status selection on payment screen

  Step 5: Submit and Confirm
    [ ] Review all uploaded documents
    [ ] Submit application
    [ ] Download and save filing receipt
    [ ] Note application number and confirmation number
    [ ] Save all correspondence

======================================================================
POST-FILING ACTIONS
======================================================================

  Immediately After Filing:

    [ ] Save filing receipts for both applications
    [ ] Note application serial numbers
    [ ] Update cross-references in each application with the
        other's serial number (can be done by amendment)
    [ ] Calendar all deadlines

  Within 3 Months of Filing:

    [ ] File any supplemental IDS if additional prior art is found
    [ ] File certified copies of any priority documents (if PCT)

  12-18 Months After Filing:

    [ ] Expect First Office Action from USPTO examiner
    [ ] Attorney reviews and prepares response
    [ ] Response due within 3 months of Office Action
        (extendable to 6 months with fees)

  Publication:

    [ ] Applications publish 18 months after filing (automatic)
    [ ] Can request earlier publication
    [ ] Can request non-publication (US-only filing)


======================================================================
PCT INTERNATIONAL FILING (OPTIONAL)
======================================================================

  If international protection is desired:

  [ ] File PCT application within 12 months of US filing
      (or within 12 months of first public disclosure if
       PCT is the first filing)
  [ ] Filing at USPTO as Receiving Office (RO/US)
  [ ] Designate target countries/regions:
      [ ] US (35 U.S.C. 371 national phase)
      [ ] China (CNIPA)
      [ ] Europe (EPO)
      [ ] Japan (JPO)
      [ ] Korea (KIPO)
      [ ] Other: _______________________
  [ ] Pay PCT fees (approximately $958 per application,
      micro entity)
  [ ] National phase entry: 30-31 months from priority date
